รายงานโครงงาน
ระบบจัดการยืม-คืนอุปกรณ์ห้องสมุดอัจฉริยะ

ระบบจัดการอุปกรณ์ห้องสมุดแบบครบวงจร ที่เชื่อมต่อผู้ใช้งาน (Users) ผู้ดูแล (Admins) และแอปพลิเคชันสแกนเนอร์ (Scanner App) ผ่าน API เดียวกัน เพื่อยกระดับความรวดเร็วและแม่นยำในการให้บริการ

เครื่องมือและเทคโนโลยีที่ใช้ (Tech Stack)

Frontend (ส่วนแสดงผล)

  • ✓
    React.js - พัฒนาส่วนผู้ใช้ ส่วนแอดมิน และแอปมือถือ
  • ✓
    Vite - Build Tool ที่ให้ความเร็วในการพัฒนา (HMR)
  • ✓
    Tailwind CSS - จัดทำ UI สมัยใหม่ สวยงาม (Glassmorphism, Animations)
  • ✓
    Html5-Qrcode - ไลบรารีสำหรับเปิดกล้องมือถือสแกน QR Code

Backend & Database

  • ✓
    Node.js & Express.js - รันเซิร์ฟเวอร์และให้บริการ RESTful API
  • ✓
    Socket.io - เทคโนโลยี WebSockets สำหรับรับส่งข้อมูลอัปเดตสถานะแบบ Real-time ทันทีโดยไม่ต้องรีเฟรชหน้าจอ
  • ✓
    MySQL - ฐานข้อมูลเชิงสัมพันธ์ เก็บข้อมูลอุปกรณ์ ยูสเซอร์ และประวัติยืมคืน
  • ✓
    JWT (JSON Web Token) - ระบบ Authentication ยืนยันตัวตนความปลอดภัยสูง

นวัตกรรมและฟีเจอร์เด่น (Innovations)

📸

Smart QR Code Scanner

เปลี่ยนสมาร์ทโฟนของแอดมินให้เป็นเครื่องสแกน ยิงโค้ดจ่ายของหรือรับคืนได้แบบ Real-time พร้อมเสียงแจ้งเตือนและ UI เต็มจอแบบแอปพลิเคชันจริง

⚡

Real-time Sync (Socket.io)

ใช้นวัตกรรม WebSockets (Socket.io) ในการสื่อสารข้อมูล เมื่อแอดมินสแกนจ่ายของเสร็จ สถานะบนหน้าเว็บผู้ใช้หรือ Dashboard จะอัปเดตเปลี่ยนสถานะให้ทันทีโดยที่ผู้ใช้ไม่ต้องกดรีเฟรช (Refresh) หน้าจอ

📦

Queue & Batch Processing

ระบบสามารถจัดกลุ่มการยืมหลายๆ ชิ้นให้กลายเป็น "คิวเดียว" (เช่น รหัสคิว LB001) ทำให้เจ้าหน้าที่สามารถเช็คลิสต์จ่ายอุปกรณ์ทีละชิ้นได้โดยไม่สับสน

✨

Micro-Animations & UI

ออกแบบอินเทอร์เฟซด้วยหลักจิตวิทยาผู้ใช้ มีแอนิเมชันตอนสแกนสำเร็จ/ผิดพลาด ช่วยให้ใช้งานง่าย ไม่ต้องเพ่งหน้าจอ

กระบวนการทำงานแบบละเอียด (Detailed Work-Flow)

1. ขั้นตอนการจองอุปกรณ์อย่างละเอียด (Detailed Reservation Process)

1

ผู้ใช้งานเข้าสู่ระบบ (User Login)

ผู้ใช้เข้าสู่หน้าเว็บไซต์หลัก (User Web) และทำการล็อกอินด้วยรหัสนักศึกษาหรือรหัสบุคลากร เพื่อเข้าถึงฟังก์ชันการจองอุปกรณ์

2

ค้นหาอุปกรณ์ที่ต้องการ (Browse Equipment)

ผู้ใช้สามารถใช้ช่องค้นหาหรือเลือกตามหมวดหมู่ (เช่น กล้อง, ไมโครโฟน, สายไฟ) ระบบจะแสดงรายการอุปกรณ์พร้อมสถานะปัจจุบัน หากสถานะเป็น "ว่าง" หมายความว่าสามารถทำการจองได้

3

ตรวจสอบรายละเอียดและเพิ่มลงตะกร้า (Check Details & Add to Cart)

เมื่อคลิกที่อุปกรณ์ ระบบจะแสดงรายละเอียด สเปค และเงื่อนไขการยืม หากผู้ใช้ต้องการจองล่วงหน้า ให้กดปุ่ม "เพิ่มลงตะกร้า" (สามารถเลือกหลายรายการเพื่อจองพร้อมกันได้)

4

กำหนดวันและเวลาที่ต้องการ (Set Reservation Schedule)

ผู้ใช้เข้าไปที่ตะกร้าจอง ระบบจะให้ระบุ "วันที่และเวลาที่ต้องการเข้ามารับของ" รวมถึง "กำหนดส่งคืน" เพื่อให้ระบบคำนวณและตรวจสอบว่าไม่มีการจองซ้อนทับกัน

5

ยืนยันการจอง (Confirm Reservation)

ผู้ใช้ตรวจสอบข้อมูลความถูกต้องและกดยืนยัน ระบบจะเปลี่ยนสถานะอุปกรณ์เป็น "ถูกจอง (Reserved)" เพื่อล็อกสิทธิ์ไว้ให้ผู้ใช้ และสร้างรหัสคิว (Queue QR Code) ให้ผู้ใช้เตรียมนำมารับของตามเวลานัดหมาย

1.2 ขั้นตอนการต่อคิว (Waiting List Process - กรณีอุปกรณ์ไม่ว่าง)

1

ค้นหาอุปกรณ์ที่ต้องการ (Browse Equipment)

ผู้ใช้ค้นหาอุปกรณ์ที่ต้องการยืมผ่านหน้าเว็บไซต์ แต่พบว่าอุปกรณ์ชิ้นนั้นมีคนยืมไปหมดแล้ว

2

อุปกรณ์เหลือ 0 ชิ้น (Out of Stock)

ระบบแสดงสถานะว่าอุปกรณ์ "ไม่ว่าง (0 ชิ้น)" หรือกำลังถูกยืมโดยบุคคลอื่นอยู่

3

กดจองต่อคิว (Join Waiting List)

ผู้ใช้สามารถกดปุ่ม "จองต่อคิว (Waitlist)" สำหรับอุปกรณ์ชิ้นนั้น เพื่อเป็นการเข้าคิวรอเมื่อมีคนนำอุปกรณ์มาคืน

4

รับการแจ้งเตือนและเตรียมมารับของ (Notify & Pickup)

เมื่อคิวก่อนหน้านำอุปกรณ์มาคืน ระบบจะส่งการแจ้งเตือน (Notification) ไปยังผู้ใช้ที่ต่อคิวไว้เป็นคิวแรก ผู้ใช้ต้องเดินทางมารับอุปกรณ์ภายในเวลาที่กำหนด (เช่น ภายใน 2 ชั่วโมง)

5

สแกนยืนยัน QR Code เพื่อรับอุปกรณ์ (Scan QR to Receive)

ผู้ใช้เดินทางมาที่เคาน์เตอร์ นำรหัสคิว (Queue QR Code) ให้แอดมินสแกนยืนยันสิทธิ์ และแอดมินสแกนที่ตัวอุปกรณ์เพื่อบันทึกการยืมให้สมบูรณ์

6

คืนอุปกรณ์ (Return Equipment)

เมื่อใช้งานเสร็จ นำอุปกรณ์กลับมาส่งคืนที่เคาน์เตอร์ แอดมินสแกนรับคืน เพื่อให้อุปกรณ์วนกลับไปแจ้งเตือนคิวถัดไปที่กำลังรออยู่

2. ขั้นตอนการยืมและรับอุปกรณ์อย่างละเอียด (Detailed Borrowing Process)

1

ผู้ใช้งานเข้าสู่ระบบ (User Login)

ผู้ใช้ (นักศึกษาหรือบุคลากร) เข้าสู่เว็บไซต์ User Web และทำการเข้าสู่ระบบด้วยรหัสประจำตัว เพื่อยืนยันสิทธิ์ในการยืมอุปกรณ์

2

ค้นหาและเพิ่มลงตะกร้า (Browse & Cart)

ผู้ใช้เลือกดูรายการอุปกรณ์ที่สถานะ "ว่าง" กดเพิ่มอุปกรณ์ที่ต้องการลงในตะกร้า (สามารถยืมหลายชิ้นพร้อมกันใน 1 คิวได้)

3

สร้างรหัสคิวการยืม (Generate Queue QR)

ผู้ใช้เข้าไปที่ตะกร้า ระบุวันที่ต้องการรับ-คืน แล้วกดยืนยัน ระบบจะผูกรายการทั้งหมดเข้าด้วยกันและสร้าง Queue QR Code ขึ้นมาเพื่อเป็นตัวแทนของคิวนี้

4

ติดต่อเจ้าหน้าที่ (Contact Admin)

ผู้ใช้เดินไปที่เคาน์เตอร์บริการห้องสมุด พร้อมเปิดหน้าประวัติการยืมในมือถือ เพื่อแสดงรหัส Queue QR Code ให้เจ้าหน้าที่ดู

5

แอดมินเตรียมระบบ (Admin Scanner Login)

เจ้าหน้าที่เปิดเว็บแอปพลิเคชัน Mobile Scanner บนสมาร์ทโฟนของตนเอง และทำการล็อกอินด้วยบัญชีแอดมิน เพื่อเข้าสู่โหมดสแกน

6

สแกนรหัสคิวผู้ใช้ (Scan Queue QR)

เจ้าหน้าที่ใช้มือถือสแกน Queue QR Code จากหน้าจอของผู้ใช้ ระบบจะดึงรายการอุปกรณ์ทั้งหมดที่ผู้ใช้ขอยืม มากางเป็น Check-list บนมือถือของเจ้าหน้าที่ทันที

7

หยิบอุปกรณ์และสแกนยืนยันความถูกต้อง (Cross-Validation)

เจ้าหน้าที่เดินไปหยิบอุปกรณ์จริงตามรายการ จากนั้นนำมือถือ สแกน QR Code ที่ติดอยู่บนตัวอุปกรณ์ทีละชิ้น เพื่อยืนยันว่าหยิบมาถูกต้องตรงกับในคิว (หากสแกนผิดชิ้น ระบบจะขึ้นแจ้งเตือนสีแดง)

8

รายการยืมเสร็จสมบูรณ์ (Complete Checkout)

เมื่อเจ้าหน้าที่สแกนอุปกรณ์ครบทุกชิ้น ระบบจะติ๊กถูกครบทุกรายการ และเปลี่ยนสถานะคิวเป็นเสร็จสมบูรณ์ (สถานะอุปกรณ์ถูกเปลี่ยนเป็น "ถูกยืม") เจ้าหน้าที่ส่งมอบอุปกรณ์ให้ผู้ใช้ เป็นอันเสร็จสิ้น

3. ขั้นตอนการคืนอุปกรณ์ (Return Process)

1

รับของคืนที่เคาน์เตอร์

ผู้ใช้ไม่ต้องทำรายการใดๆ ในระบบ เพียงนำอุปกรณ์มาส่งคืนที่เคาน์เตอร์ให้เจ้าหน้าที่

2

แอดมินสแกนคืนอุปกรณ์

แอดมินใช้ Mobile Scanner App สแกน QR ที่ตัวอุปกรณ์โดยตรง (ไม่ต้องใช้รหัสคิว) ระบบจะตรวจพบโดยอัตโนมัติว่าใครเป็นผู้ยืมชิ้นนี้

3

อัปเดตสถานะสำเร็จ

ระบบจะบันทึกเวลาคืน ยกเลิกสถานะการยืม และปรับให้อุปกรณ์กลับมาเป็นสถานะ "ว่าง" (Available) ให้คนอื่นสามารถจองต่อได้ทันที

สรุปภาพรวมของโครงงาน (Conclusion)

โครงงาน ระบบจัดการยืม-คืนอุปกรณ์ห้องสมุดอัจฉริยะ เข้ามาแก้ปัญหาความล่าช้าและความผิดพลาดในการเบิกจ่ายอุปกรณ์ โดยเปลี่ยนระบบจากเดิมที่ต้องจดบันทึกหรือคีย์รหัสเอง มาเป็นการใช้สถาปัตยกรรม แยกส่วน Frontend 3 แอปพลิเคชัน (User, Admin, Mobile Scanner) ควบคุมผ่าน API กลาง

จุดเด่นที่สำคัญที่สุดคือการพัฒนาระบบ Batch-Queue Scanning ที่สามารถรวบรวมอุปกรณ์หลายรายการไว้ในรหัสคิวเดียว และป้องกันข้อผิดพลาดด้วยการบังคับให้เจ้าหน้าที่ต้องสแกน QR Code ที่ตัวอุปกรณ์จริง (Cross-Validation) ก่อนจ่ายของ

ในแง่ของการออกแบบ มีการใช้เทคนิค UI/UX สมัยใหม่ เช่น Glassmorphism, Micro-interactions และ PWA-like Experience บนมือถือ ทำให้แอปพลิเคชันมีความเป็นมืออาชีพ ใช้งานง่าย นำไปสู่การให้บริการห้องสมุดที่มีประสิทธิภาพและทันสมัยในยุคดิจิทัลอย่างแท้จริง
